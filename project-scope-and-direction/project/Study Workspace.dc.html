A provider tells an injector how to create a dependency. The injector hierarchy decides which instance a component gets.

Where to provide

  • providedIn: 'root' gives one app-wide instance and is tree-shakable
  • Component providers: [] give a new instance per component subtree
@Component({ providers: [CartService] })
// checkout gets its own cart, isolated from the header badge
